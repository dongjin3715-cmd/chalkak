# 찰칵 (Chalkak)

광고 없는 가벼운 윈도우 화면 캡처 프로그램이에요. 영역·창·전체 화면·스크롤 캡처와 예쁜 편집창이 들어 있어요.

## ⬇️ 다운로드

**[최신 버전 받기 (Chalkak.exe)](https://github.com/dongjin3715-cmd/chalkak/releases/latest/download/Chalkak.exe)**

모든 버전: [Releases](https://github.com/dongjin3715-cmd/chalkak/releases)

## 설치

1. `Chalkak.exe`를 계속 둘 폴더(예: `C:\Users\내이름\찰칵\`)에 넣고 더블클릭하세요. 설치 과정은 없어요.
2. **"Windows의 PC 보호"** (SmartScreen) 창이 뜨면, 서명되지 않은 프로그램이라서 그래요. **추가 정보 → 실행**을 눌러 주세요.
3. 작업 표시줄 오른쪽 트레이(^)에 찰칵 아이콘이 생기면 성공! 아이콘을 왼쪽 클릭하면 바로 영역 캡처, 오른쪽 클릭하면 메뉴예요.

## 주요 기능

- 영역 캡처 `Ctrl+Shift+C` (보조 `Ctrl+Shift+1`), 창 `Ctrl+Shift+2`, 전체 화면 `Ctrl+Shift+3`, 스크롤 캡처 `Ctrl+Shift+4` (설정에서 변경)
- 캡처하면 클립보드 복사(무손실 PNG 포함) + `사진\찰칵\찰칵_날짜_시간.png` 자동 저장
- 편집창: 원본 100%로 열림, 펜·형광펜·화살표·도형(네모, 둥근 네모, 동그라미, 직선, 양방향 화살표, 말풍선, 별, 숫자 스탬프)·글자·모자이크
- 그린 글자·도형·화살표는 나중에 골라서 옮기기, 크기 바꾸기, 색 바꾸기, 지우기
- 찰칵 스타일 색 고르기 창 (색 판, 투명도, 최근 색, HEX)
- 여러 모니터 · 고해상도(DPI) 지원, 광고 없음

자세한 사용법은 [사용법.txt](사용법.txt)를 보세요.

## 🔄 자동 업데이트

찰칵은 켜지고 10초 뒤, 그다음 6시간마다 이 저장소의 최신 릴리스를 확인해요.
새 버전이 있으면 **지금 업데이트 / 다음에** 알림이 뜨고, 설정의 **자동으로 업데이트**가 켜져 있으면 쓰지 않을 때 알아서 바꿔요.
받은 파일은 크기와 SHA-256을 확인한 뒤에만 바꾸고, 문제가 있으면 원래 버전으로 되돌려요.
통신은 GitHub(최신 릴리스 확인과 릴리스 파일 다운로드)하고만 해요.

설정은 `%APPDATA%\Chalkak\settings.ini`에 있어서 업데이트해도 그대로예요.

필요 환경: Windows 10 / 11 (.NET Framework 4.x 기본 포함)
