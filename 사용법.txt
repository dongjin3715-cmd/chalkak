찰칵 v1.0.1 - 광고 없는 화면 캡처

실행: 찰칵.exe 더블클릭 → 작업 표시줄 오른쪽 트레이(^ 안)에 아이콘이 생겨요.
      트레이 아이콘 왼쪽 클릭 = 영역 캡처, 오른쪽 클릭 = 메뉴.
      메뉴 맨 위에 지금 버전(찰칵 v1.0.2)이 보여요.

단축키 (설정에서 바꿀 수 있어요)
  Ctrl+Shift+C     영역 캡처 (알캡처가 켜져 있으면 알캡처가 쓰고 있어서 안 돼요.
                   알캡처를 끄면 30초 안에 찰칵에 자동으로 연결돼요)
  Ctrl+Shift+1     영역 캡처 (보조)
  Ctrl+Shift+2     창 캡처
  Ctrl+Shift+3     전체 화면 캡처 (마우스가 있는 모니터 / 설정에서 모든 모니터)
  Ctrl+Shift+4     스크롤 캡처

영역 선택 화면: 드래그 = 영역, 클릭 = 마우스 아래 창, 방향키 = 1픽셀 이동, Esc/오른쪽 클릭 = 취소
스크롤 캡처: 스크롤할 칸(브라우저 본문 등)을 클릭하거나 드래그 → 자동으로 내리면서 이어 붙여요.
             Esc를 누르거나 마우스를 움직이면 거기까지 붙여서 멈춰요.

캡처하면: 클립보드에 복사 + 사진\찰칵 폴더에 찰칵_날짜_시간.png 저장 + 편집창 열림 (설정에서 끄고 켜기)

편집창: 캡처 직후 항상 100%(실제 픽셀)로 열려요. 화면보다 크면 창을 최대화하고 스크롤로 봐요.
        Ctrl+0 화면 맞춤(고품질 축소), Ctrl+1 100%, Ctrl+휠 확대/축소, Esc 닫기

  캡처하면 도형 · 네모가 골라진 채로 열려요.
  도구: 고르기(V) 펜(P) 형광펜(H) 화살표(A) 도형(R) 글자(T) 모자이크(M), 굵기 1·2·3
  도형: 도형 버튼(▾)을 누르면 네모·둥근 네모·동그라미·직선·양방향 화살표·말풍선·별·숫자 스탬프(1,2,3…)
        테두리만 / 채우기 / 반투명 중에 고르기. 색과 굵기는 툴바에서 고른 그대로. 마지막 도형을 기억해요.
        Shift를 누르고 그리면 정사각형·정원, 직선은 45도 단위.
  글자·도형·화살표는 그린 뒤에도 고칠 수 있어요:
        눌러서 고르기 → 끌어서 옮기기, 동그란 핸들로 크기, 방향키 1px (Shift+방향키 10px), Delete 지우기
        고른 채로 툴바 색/굵기를 누르면 그 객체가 바뀌어요.
  글자: 고르면 위에 작은 막대가 떠요 - 크기 -/+ (또는 Ctrl+휠, Ctrl+[ ]), 굵게, 배경(없음/반투명/채우기), 색,
        내용 고치기(두 번 누르기 또는 Enter), 지우기. 입력 중 Shift+Enter = 줄바꿈, Enter = 넣기.
  색 +: 찰칵 색 고르기 창 (색 판, 투명도, 기본 색 16개, 최근 색 8개, HEX 입력). Enter 선택, Esc 취소.
  Ctrl+Z 되돌리기(옮기기·크기 변경 포함), Ctrl+Y 다시, Ctrl+C 복사, Ctrl+S 저장, Ctrl+Shift+S 다른 이름으로
  복사할 때는 PNG(무손실)와 비트맵을 같이 넣어서, 붙여넣는 앱에서 화질이 떨어지지 않아요.

업데이트 (배포용 Chalkak.exe)
  켜지고 10초 뒤, 그다음 6시간마다 GitHub에서 새 버전을 확인해요 (트레이 메뉴 '업데이트 확인'으로 바로 확인도 돼요).
  새 버전이 있으면 오른쪽 아래에 알림이 떠요: [지금 업데이트] / [다음에].
  새 버전을 찾으면 트레이 메뉴가 '최신 버전으로 업데이트 (vX)'로 바뀌어요. 누르면 바로 받아서 바꿔요.
  설정 > 기타 > '자동으로 업데이트'가 켜져 있으면, 고르지 않았을 때 찰칵을 쓰지 않는 동안(편집창·설정창이 닫혀 있을 때) 알아서 바꿔요.
  받은 파일은 크기와 SHA-256을 확인한 뒤에만 바꾸고, 새 버전이 제대로 안 켜지면 원래 버전으로 되돌려요.
  설정·최근 색·캡처 파일은 그대로 남아요. 기록: %APPDATA%\Chalkak\update.log

설정 파일: %APPDATA%\Chalkak\settings.ini   기록: %APPDATA%\Chalkak\log.txt
다시 빌드: build.ps1 (개인용 찰칵.exe, 업데이트 없음) / build.ps1 -Release (배포용 Chalkak.exe)
